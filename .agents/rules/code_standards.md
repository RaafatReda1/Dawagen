# Antigravity Rules: Code Organization & Technical Constraints

1. **Max 50 Lines Per File**: No file should exceed 50 lines. Break down larger files into smaller components with their own isolated `.module.css`.
2. **Components Folder Hierarchy**: The parent file path must have a `Components/` folder for sub-components.
3. **Data & Accounting Sanity**: Always cross-check financial values. Sales Revenue >= Collected Payments; Profit = Revenue - Expenses.
